# 使用说明（平板端）

适用版本：1.0.0。设备要求：Android 10 及以上平板（横屏、竖屏都可用，界面按窗口宽度自适应）。

---

## 1. 第一次启动

1. 安装 APK 后打开，主体是一面**视频墙**（卡片来自后台解析出的封面/标题/时长）；左侧导航与右侧详情栏是否常驻，取决于窗口够不够宽（见第 3 节）。
2. 顶部点「开启悬浮助手」：
   - 先授予**通知权限**（Android 13+，仅用于常驻通知，通知渠道静音、不响不振）；
   - 再跳到系统设置授予「**显示在其他应用上层**」；开启后屏幕角落出现一个可拖动的悬浮球。
   - 助手只需要这两项权限，**不申请无障碍、不申请存储、不读取你的剪贴板历史**。

## 2. 全局悬浮收藏助手（在其他 App 里收藏视频）

在任意视频 App 里看到想收藏的视频：

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| 分享（最顺手） | 视频 App → 分享 → 选择「收藏助手」 | 悬浮面板直接在**当前 App 上层**弹出，收藏完自动收起，人还停在原 App |
| 悬浮球 + 粘贴 | 复制链接 → 点悬浮球 → 点「粘贴剪贴板链接」 | 面板拿到焦点时会先自动读一次剪贴板，读不到再手动粘贴 |

> 为什么需要点一下粘贴：Android 10 起系统规定只有「正在输入框上获得焦点的 App」才能读剪贴板，
> 后台常驻服务读取剪贴板会被系统直接拦掉。本项目没有用无障碍服务去绕这条限制，
> 而是把入口做成面板上的一个按钮，安全性和省电都更稳。

面板从上到下就是四段：

1. **链接预览（只读）**：自动带出识别到的视频链接与来源站点（哔哩哔哩 / YouTube / 抖音 / 腾讯视频 / 优酷 / 小红书…），链接本身不可编辑，避免改坏导致后续无法播放。
2. **备注区（手写笔友好）**：用手写笔直接落在这一栏就能写字，不需要切输入法；也支持键盘与手写输入。
3. **标签栏（横向滚动、可多选）**：点选即高亮。栏尾是「**快速新建标签**」，点了在**面板内**就地出现一个单行输入框，确认后新标签直接进入全局标签库并自动选中，全程不跳出主 App。
4. **底部只有两个按钮**：「保存同步」和「关闭」。

点「保存同步」之后：

- 链接 + 备注 + 标签 + 来源 App + 收藏时间戳**先写进本地库并排入上传队列**（传输是纯明文 JSON：这些数据没有保密需求，
  早前的 RSA+AES 信封加密已删除，它只会让「后台解不开却回 200」这类问题变成静默丢数据）；
- 队列**一次只传一条**，传完等待后台建议的时间（响应里的 `next_wait_ms`）或设置里的上传间隔（默认 3000ms）再传下一条；
- 视频标题、封面、时长、可播地址由**后台解析后回传**，所以刚收藏时卡片显示「解析中」，解析完成才能播放；
- 屏幕下方出现约 2 秒的轻提示，面板自动收起，你回到刚才那个视频 App；
- 如果此刻断网：静默重试 3 次；仍失败就留在本地待上传队列，**联网的瞬间自动补传，不需要你手动点重试**；
- 数据先落本地数据库，所以「保存成功」和「同步成功」是两件事——离线也一定能立刻看到这条收藏。

悬浮球行为：可以拖到任意位置，靠近左右边缘会自动贴边并**半隐**成一条细边（不遮挡第三方 App 的正文和按钮），
轻点细边先展开成完整球，再点一次打开收藏面板。位置在重启后仍然保留。

## 3. 主 App：以视频墙为主体

布局完全跟着**窗口宽度**走，跟横竖屏无关，也不再强制方向：

| 窗口宽度 | 排版 |
| --- | --- |
| `< 900dp`（竖屏平板、分屏小窗） | 整屏视频墙 + 顶部横向滚动筛选条；点卡片打开**整屏详情页**，返回键回到视频墙 |
| `900 ~ 1119dp`（普通横屏平板） | 左栏导航 + 视频墙；详情仍然整屏打开 |
| `>= 1120dp`（大屏横屏） | 左栏导航 + 视频墙 + 常驻右栏详情/播放器（三栏） |

视频墙列数按可用宽度算，2~5 列自适应（卡片最小宽度 240dp，窄屏 200dp）。

### 顶部栏

- **搜索框**：可搜后台返回的标题、作者、站点，也能搜备注、链接、来源；搜索词转屏后不丢。
- **刷新**：向后台重新拉取「还没解析出来」的那些条目的解析结果（正在拉时变成转圈，不可重复点）。
- **粘贴链接**：在主 App 内直接收藏一条链接（复用悬浮面板那套 UI，不需要悬浮窗权限）。
- 状态胶囊：`离线` / `待上传 N`（队列里还有几条没传） / `未同步 N` / `待解析 N`。

### 视频卡片

- 封面 16:9，由后台返回；**还没解析出来时没有封面**，卡片用主题渐变占位并在左上角标注状态：
  「解析中」（转圈）/「已解析」/「演示源」（mock 服务给的假数据）/「解析失败」。
- 右下角是时长，左下角细条是观看进度，中间圆三角表示这条已经可以直接播。
- 一行小字是「作者 · 站点」，没解析出来时退回链接主机名。
- 底部小圆点是同步状态：绿=已同步，黄=等待后台上传，红=重试耗尽（联网后仍会自动补传），灰=离线仅本地；
  右侧文字标记「已缓存」（离线可整片播放）或「缓存中」。
- **点卡片**=打开详情并让播放器对准后台给的播放地址；**长按卡片**=进入多选，可全选、移动到…、批量删除。
- 解析失败的卡片上有「重新解析」按钮，会让后台丢弃旧结果重算。

### 详情页 / 播放器

- 视频直接在这一栏播，不全屏跳转；控制条支持**播放/暂停、拖动进度、0.75x~2x 倍速、全屏**。
  全屏后同一个播放器铺满整屏并自动隐藏系统栏，退出全屏播放不断点。
- 标题、封面、时长都由后台给出，本地**不可编辑标题**；可编辑的是备注，可调整标签、切换归档分类、删除这条收藏。
  任何改动都是「先落本地库 + 排入上传队列」，按队列节奏自动传，不需要手动点保存同步。
- 「缓存到本地」把这条视频整片下载到本地缓存（显示进度，可随时取消）；缓存后离线可播。
- 「信息」区列出来源、原始链接、收藏时间、观看进度、解析状态与当前同步状态。

## 4. 设置

顶部齿轮进入设置，五组卡片：

- **同步服务**：接口地址（要填到包含前缀的完整 base，如 `http://192.168.1.20:8787/api/v1`）、访问令牌（Bearer）、
  **上传间隔**（预设 0=不限速 / 1s / 3s / 10s / 30s，默认 3000ms；后台若回 `next_wait_ms` 以后台为准），
  底部显示本机设备标识（后端用它区分同一账号下的不同平板）。
  打包时可以用 `-PSYNC_ENDPOINT=...` 或 CI 的 Repository variable 固化默认地址；传输不加密，不再需要往包里塞公钥。
  想接自己的后台，字段、状态码与校验规则见 `docs/同步后台接口说明.md`。
- **同步队列**：待上传 / 未同步条数，以及「立即重试」（把已耗尽重试次数的任务重新排队）。
- **全局悬浮收藏助手**：悬浮球常驻开关，以及「打开面板时自动读剪贴板」开关（关掉后只能手动点粘贴或用分享入口）。
  未授权时这里会给出跳转系统悬浮窗授权的按钮。
- **播放与缓存**：默认倍速（0.75x~2x）、本地缓存占用（`已用 / 上限`）。
- **缓存上限**：128MB~2GB 五档，以及「清空本地视频缓存」；清空只删视频文件，收藏记录、备注和标签不受影响。

通知栏那条静默常驻通知带两个动作：「打开设置」直接跳到主 App 设置页，「停止」会同时关掉助手偏好，
下次进主 App 不再自动拉起。

## 5. 离线能力

- 收藏记录、备注、标签全部存在设备本地数据库，断网时列表、搜索、筛选、编辑与删除照常可用。
- 已缓存的视频离线可直接播放；未缓存的条目在断网时仍可浏览详情，点播放会给出明确的网络错误提示。
- 断网期间的改动（新增/编辑/删除）都会排队，联网后自动补传，不会丢。

## 6. 常见问题

**悬浮球没有出现？** 系统把「显示在其他应用上层」收回了（部分厂商在重启或清理后台后会重置）。
进设置重新授权，或在设置里把助手开关关掉再打开。

**面板里点「粘贴剪贴板链接」提示读不到？** 请先在视频 App 里点一次「复制」，再回来粘贴；
部分厂商 ROM 会在剪贴板里带隐私遮罩，这种情况用「分享 → 收藏助手」最稳。

**删除后云端还在？** 删除是软删除 + 排队上传，右栏信息区会先显示「等待后台上传」，同步成功后本地条目才彻底清理。

**换了平板怎么恢复收藏？** 在新平板设置里指向同一个后端地址，首次打开时本地库为空会自动向后端回填。
