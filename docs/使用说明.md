# 使用说明（平板端）

适用版本：1.0.0。设备要求：Android 10 及以上平板（横屏、竖屏都可用，界面按窗口宽度自适应）。

---

## 1. 第一次启动

1. 安装 APK 后打开，主体是一面**视频墙**（卡片直接摆出后台解析回来的内容），点卡片在墙上盖一层**聚焦遮罩**看全文与逐段浏览；
   筛选、标签、同步状态收在顶栏的「筛选」抽屉里（见第 3 节）。
2. 顶部点「开启悬浮助手」：
   - 先授予**通知权限**（Android 13+，仅用于常驻通知，通知渠道静音、不响不振）；
   - 再跳到系统设置授予「**显示在其他应用上层**」；开启后屏幕角落出现一个可拖动的悬浮球。
   - 助手只需要这两项权限，**不申请无障碍、不申请存储、不读取你的剪贴板历史**。

## 2. 全局悬浮收藏助手（在其他 App 里收藏视频）

在任意视频 App 里看到想收藏的视频：

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| 分享（最顺手） | 视频 App → 分享 → 选择「收藏助手」 | 悬浮面板直接在**当前 App 上层**弹出，收藏完自动收起，人还停在原 App |
| 悬浮球 + 粘贴 | 复制链接 → 点悬浮球 → 点「粘贴剪贴板链接」 | 面板拿到焦点时会先自动读一次剪贴板，读不到再手动粘贴 |

> 为什么需要点一下粘贴：Android 10 起系统规定只有「正在输入框上获得焦点的 App」才能读剪贴板，
> 后台常驻服务读取剪贴板会被系统直接拦掉。本项目没有用无障碍服务去绕这条限制，
> 而是把入口做成面板上的一个按钮，安全性和省电都更稳。

面板从上到下就是四段：

1. **链接预览（只读）**：自动带出识别到的视频链接与来源站点（哔哩哔哩 / YouTube / 抖音 / 腾讯视频 / 优酷 / 小红书…），链接本身不可编辑，避免改坏导致后续无法播放。
2. **备注区（手写笔友好）**：用手写笔直接落在这一栏就能写字，不需要切输入法；也支持键盘与手写输入。
3. **标签栏（横向滚动、可多选）**：点选即高亮。栏尾是「**快速新建标签**」，点了在**面板内**就地出现一个单行输入框，确认后新标签直接进入全局标签库并自动选中，全程不跳出主 App。
4. **底部只有两个按钮**：「保存同步」和「关闭」。

点「保存同步」之后：

- **同一条链接重复分享不会重复入库**：保存前按收到的链接**原样**比对，命中就只提示「这条链接已经收藏过了（标题）」——
  不写库、不排队、也不会为它新建标签，面板保持打开、你输入的备注与已选标签都不动，看完提示点「关闭」就行。
  原样比对意味着不做参数归一化：B 站的 `?p=2` 分 P、抖音带不同 `vd_source` 的同一视频会被当成不同收藏（这是有意的，
  分 P 确实是不同内容）。删除过的链接再分享会正常重新入库。
- 链接 + 备注 + 标签 + 来源 App + 收藏时间戳**先写进本地库并排入上传队列**（传输是纯明文 JSON：这些数据没有保密需求，
  早前的 RSA+AES 信封加密已删除，它只会让「后台解不开却回 200」这类问题变成静默丢数据）；
- 队列**一次只传一条**，传完等待后台建议的时间（响应里的 `next_wait_ms`）或设置里的上传间隔（默认 3000ms）再传下一条。
  这个间隔由所有出站请求共用的那道闸门把住：失败退避重传、手动「立即重试」、翻页取后台的收藏、手动重新解析，都照样排队，不会有一路径插队；
- 内容信息（标题、作者、站点、封面、可播地址，外加一句 `summary` 说明这条链接里有什么、以及 `segments[]` 素材清单——图和多段视频）
  由**后台在同一次上传的响应里解析并带回**：`POST /sync` 回执一落库，卡片就是完整的样子，不存在「先有链接、等一会儿才有内容」
  那段时间，界面上也就没有「解析中」这种状态。一条链接可能解析出多个素材，App 会全部展示；
- 屏幕下方出现约 2 秒的轻提示，面板自动收起，你回到刚才那个视频 App；
- 如果此刻断网：静默重试 3 次；仍失败就留在本地待上传队列，**联网的瞬间自动补传，不需要你手动点重试**；
- 数据先落本地数据库，所以「保存成功」和「同步成功」是两件事——离线也一定能立刻看到这条收藏。

悬浮球行为：可以拖到任意位置。**球心离左右边缘不到一颗球的宽度**时，松手就自动贴边并**半隐**成一条 12dp 的细边
（不遮挡第三方 App 的正文和按钮）；离边缘远就完整贴边停靠（只留 4dp 安全边距，不再内缩 20mm——那颗 20mm 的要求
说的是 App 自己界面里的按钮，悬浮球要的恰恰是贴边）。轻点细边先展开成完整球，再点一次才打开收藏面板。位置在重启后仍然保留。

有待办要说的时候，**数字直接占住球心、替掉那颗收藏图标**，整颗球的底色就是状态：
**红=有条目重试耗尽或被后台拒绝**（需要你动手），**灰=离线攒着没发**，**黄=待同步**，图标原样就是没事。
数字超过 99 只显示 `99+`。半隐时球心在屏幕外，那种状态只看得到底色，点展开才读得到数字；
不想要数字就去设置里关掉「悬浮球显示同步角标」。

## 3. 主 App：视频墙 + 聚焦遮罩两层

界面只有两层：**视频墙**始终铺满主区域，点卡片后在它上面盖一层**聚焦遮罩**。
墙的列数跟着**窗口宽度**走；遮罩层跟着**宽度 + 方向**走（够宽且确实是横着才分两栏）。
不强制方向；旋转、分屏、折叠屏切换都不重建 Activity，
浏览位置、滚动进度、已解码的封面与备注草稿都还在。

| 场景 | 排版 |
| --- | --- |
| 视频墙 | 整屏铺满，2~5 列按可用宽度自适应（卡片最小宽度 240dp，可用宽度不足 600dp 时降到 200dp），与横竖屏无关 |
| 遮罩层 · 单栏（可用宽度 < 840dp，或高 ≥ 宽：手机、平板竖屏） | 一屏一条：画面整屏铺满，段号 / 标题 / 作者 / 文案叠在画面底部，详情收进底部三档抽屉 |
| 遮罩层 · 两栏（可用宽度 ≥ 840dp 且宽 > 高：平板横屏） | 9:16 画面居中在左栏，右栏宽 = max(220dp, 25%) 常驻详情，可收起成右缘一个把手 |

以前按宽度切三栏，导航栏和详情栏各吃掉一条，最该看的解析内容反而最小——现在这两条宽度整条还给墙。
遮罩层这一版确实重新分了左右，但只在够宽的横屏上给，右栏只占 25% 而且随时收得起来 —— 收起后又是整屏画面。

### 顶部栏

- **标题区**：本地只是后台的分页缓存，所以这里跟着缓存进度换说法 —— **只有还有页没取回时**才说「共 N 条 · 已取回 M 条」；
  页取全了就说「共 M 条」（离线再加一个「· 离线」）。取全之后不再引用后台那个总数：它只在翻页时刷新，
  删掉一条就会说出「共 20 条 · 已取回 19 条」这种把刚删的那条说成还没取回的话。墙头那条分数式文案同一个口径。
  其余动作都收在右侧一排里，放不下时那一排自己横向滚。
- **搜索**：默认收成一个图标，点开才占一整行；可搜后台返回的标题、作者、站点，也能搜备注、说明、链接、来源；收起时自动清空，搜索词转屏不丢。
- **筛选**：一个入口打开抽屉，里面是同步状态（离线/待同步/失败 + 「仅看未同步」+「立即重试」）、
  标签多选、标签库管理（改名保留既有关联，删除只解除关联）、新建标签、本地缓存占用与「从后台加载」。
  底部的「本地缓存占用」是**视频 + 图片两个目录之和**（打开抽屉时重新量一遍），下面小字按目录各报多少 ——
  只给一个数就说不清该去设置里点哪个「清空」。设置页那两个 `已用 / 上限` 仍按目录分开列。
- **上传那颗是文字按钮，不是刷新图标**。原先那颗圆形箭头怎么看都像「刷新墙列表」，现在按当前该做什么直接写出来：
  有失败的 → 红字「重试上传 N」；队列里还有没传完的 → 「继续上传 N」；正在传 → 原地转圈；一切干净 → **这颗按钮不出现**
  （没事可做就别占一个位置让人去点）。点它做的事是「把重试耗尽、被后台拒绝的条目重新排队并立刻跑一轮队列」，
  四种情况都会回一句轻提示，不再有「点了没反应」。列表要刷新请用筛选抽屉里的「从后台加载」。
- **粘贴链接**：在主 App 内直接收藏一条链接（复用悬浮面板那套 UI，不需要悬浮窗权限）。
- 状态胶囊只有三枚：`离线`（连不上后台） / `待同步 N`（队列里还会自动再传的有几条） /
  `失败 N`（重试耗尽或被后台拒绝，需要你动手）。三枚都只数**上传队列**，别的什么都不数：
  内容信息是随上传一起回来的，所以没有独立的「待解析」；解析失败只是那条卡片上的一行字，不占全局计数。
  失败那批已经从待同步里减掉，不会重复计。

### 视频卡片：一眼看清这条内容是什么

卡片不再自我介绍（作者 · 站点 · 同步状态文字都撤了），而是按后台给的 `segments[]` **真实构成**变形：

- **1 个素材**：一整张封面，中间圆三角表示可直接播。
- **纯图集（≤4 张）**：等分拼格，每张都是正文，没有主次之分。
- **有视频或多素材**：首图放大 + 右侧缩略条（列数多的窄卡只排 2 块，避免糊成马赛克）。
- **封面左上角**一枚小标：这条的构成（`4图 · 2段` / `7图` / `视频`），扫一眼就知道点进去是翻图还是看片。
- **封面底部那一条**：标签在左（最多露 2 个，剩下的收进「+N」，名字再长是它自己尾部省略），
  右边依次是首段「清晰度 · 时长」、没露全的段数「+N」、同步状态色点（绿=已同步，黄=待同步，红=失败/离线），
  再跟一个色点表示已缓存/缓存中。标签压在从透明到近黑的渐变垫底上，花封面也读得清。
  卡片上的标签只做识别，点它没有反应，按标签筛选在顶栏抽屉里。
- **文字区两行**：标题一行（后台给的标题，没标题才退回链接主机名）+ 后台那句 **summary 两行**（「这条链接里有什么」）。
- 一条都还没有内容时用主题渐变占位，写明是「解析失败」（附后台给的原因）还是「内容信息还没取回来」，
  文字区的说明也跟着换成失败原因。**解析失败不占任何全局计数** —— 上传成没成、内容有没有解析出来是两件事，
  混成一个状态就没人知道该点「重试上传」还是该改链接。
- 封面最底 3dp 细条是观看进度。
- **点卡片**=打开遮罩层；**长按卡片**=进入多选，可全选、批量删除。

### 聚焦遮罩层：一屏一条，逐段浏览后台回来的内容

- **画面里左右滑 = 翻段**（图集就是翻图，多段视频就是翻段）；**上下滑 = 换一条收藏** ——
  换条走的是同一个竖向 pager，跟手、回弹、吸附和翻段一模一样，一屏正好一条、松手就贴边，一次也只翻一页。
  到头还继续抹就按 pager 默认的 overscroll 回弹，同时居中冒一句「已经是第一条 / 已经是最后一条」
  （翻段那一下报「第一段 / 最后一段」，位置贴着画面顶），1.2 秒自己走。
  换条的顺序是**随机的**：打开遮罩那一刻把待看的条目洗一次牌，进来那条固定在第一页，之后一路往上滑就是随机游走，
  往下滑能退回刚才看过的那条。滑动过程中的相邻页只显示那张封面（一个 ExoPlayer 同时只能喂一个画面）。
  头部不放 `‹ ›` 图标：那两个尖角一直被当成「翻页」，而它干的其实是「换一条」；关闭键浮在画面左上角。
- **画面整屏铺满，信息压在画面底部**：段号角标「第 n/m 段」→ 标题 → 作者/站点 → 文案（最多两行，
  真被裁过才给「展开 / 收起」）→ 「详情」入口，底边是一条 2dp 进度条（触控热区 18dp）。
  文案背后那层渐变只盖画面、不吃点击：点画面 = 暂停/继续，暂停时正中留一个 ▶；拖进度条只改指针、
  松手才 seek，那 18dp 按下的第一下就被它消费掉，不会顺手把视频停了。
- **段条保留**：就在文案上面那行，一眼看清这条内容由几段、各是什么，点哪段跳哪段，当前段会自动滚进视野并高亮。
  只有一段时横滑禁用 —— 单段没什么可翻的。
- **竖屏的详情 = 底部抽屉三档**（收起 / 半屏 / 全屏 96%）：点「详情」从**半屏**起，跟手拖、松手按最近档位吸过去，遮罩随抽屉升高变暗
  （最深 60%）；点遮罩收回，返回键也先收抽屉再关遮罩；抽屉开着时上下滑不再换条 —— 竖向手势归抽屉。
- **平板横屏的详情 = 常驻右栏**：宽 = max(220dp, 屏宽 25%)，`›` 收起、右缘那个竖排「详情」把手点回来，
  收起后画面铺回整栏。横屏不再有底部「详情」入口（右栏就是入口），也没有抽屉、遮罩和拖拽手柄。
  右栏自己就在竖向滚，嵌套滚动实测**不交接**（滚到头也换不了条），所以栏左边留一条 40dp 的**手势带**：
  上下抹一下只把竖向 pager 推一页，跟画面里直接抹同一套吸附、同一个落定装载，换条因此仍只有一个来源。
- 图片段**没放大时单指横滑就是翻页**，双指才缩放、双击复原——缩放手势只在自己确实接管了时才消费事件，
  不会再从父级手里把单指拖动抢走，图集能从第一张一路翻到最后一张。右上角的 ⛶ 把这一张铺满整屏；
  全屏里同样能左右翻，**只在图片之间翻**，翻到哪一张就把段号记到哪一张，退出全屏后遮罩层停在同一张图。
  图集段两种方向都**整张显示、不裁切**（按铺满裁的是视频段），缩放提示挪到画面顶部，不再和底部文案叠在一起。
  视频段在当前段直接挂播放器，其它段先显示封面，点一下才翻过去开始播
  （一个 ExoPlayer 实例同时只能喂一个画面，所以相邻页不抢 surface）。
- **段与段各自记住看到哪**：中途翻走再翻回来，从上次的位置继续；每段进度分别落盘。进度只在本机，不上传后台。
  旋转不换 Activity，条、段、播放位置与抽屉/右栏状态都原地不动，播放器也不重建。
- **详情里有什么**（竖屏抽屉与横屏右栏是同一份内容）：播放（时间、倍速选择器、全屏）、内容说明（summary 全文 + 构成标签）、
  当前段位置与小标题、上次看到的时间、后台信息（作者/站点/清晰度/总时长/解析时间/收藏时间）、同步状态、
  **「重新解析」按钮**（任何时候都在，不只在没内容的时候才出现）、备注编辑、**标签点一下即生效**（含就地新建标签）、
  缓存到本地/取消、删除这条收藏。倍速与全屏原先长在画面底部的控制条上，这一版控制条撤了，就搬进「播放」那一行。
- **关掉遮罩 = 停下来**。回到墙上时滚动位置不动，刚才那条卡的边框会闪一下告诉你「还站在这儿」，
  播放器已经暂停——以前这里只解除了绑定没暂停，声音会跟到墙后面继续放。
- 这条没有内容信息时，画面位直接变成说明台：讲清是解析失败还是还没取回来（附后台原因），
  详情里那颗「重新解析」就是它的出口。

### 播放器

遮罩层里画面就是那一屏：**点一下暂停/继续**，底边那条 2dp 进度条贴着画面拖。**全屏**才是另一套形态：
同一个播放器铺满整屏并自动隐藏系统栏，控制条带**播放/暂停、拖动进度、倍速选择器、全屏**四样，
倍速是 0.75x~2x 五档、点当前倍速弹出选择器选档（不平铺，窄屏不挤进度条也不误触）；
**全屏时点画面只负责唤出/收起控制条**（播放中 3.5 秒自动收起），退出全屏用控制条上的按钮或返回键，
点一下屏幕不会掉出全屏。退出全屏后遮罩层还在原段原位继续播放，不断点。
全屏这一层按当前段的素材分派：视频段铺播放器，图集段铺大图，两条路退出后都回到遮罩的同一段。

## 4. 数据从哪来、离线能看什么

- **后台是收藏的事实来源**，本地这张表是它的**分页缓存**：冷启动发现缓存空着就自动去后台取第一页，
  视频墙滚到离底还有两屏再静默补一页，列表尾部会显示「正在从后台取下一页」或「到底了 · 本地缓存 N 条」。
  一次一页 50 条，不会因为某人收藏了八千条链接就把 App 拖死。
- 每一页都同时带回**后台的收藏总数**，**只有还有页没取回时**墙头才写成「已取回 50 / 1280 条」——你知道往下滚还有，
  而不是看到 50 条以为就这么多。页取全了本地就是后台的镜像，这时只说本地条数：那个总数只在翻页时刷新，
  再拿它来比就会出现「删掉一条 = 共 20 条 · 已取回 19 条」这种把刚删的那条说成还没取回的话。
  后台不下发这个数时，界面同样只报本地实有的条数，不编数字。
- 写操作仍然是「先落本地缓存 + 排入上传队列」，按队列节奏自动传，不需要手动点保存同步；
  所以刚收藏那一条在断网时也立刻看得见，联网后补传。
- 标题、封面、时长都由后台给出，本地**不可编辑标题**；可编辑的是备注，可调整标签、删除这条收藏。
- 「缓存到本地」把这条视频整片下载到本地缓存（显示进度，可随时取消，播放器与缓存共用同一份数据，边播边存）；缓存后离线可播。
- 收藏记录、备注、标签都在设备本地数据库里，断网时列表、搜索、筛选、编辑与删除照常可用 ——
  能翻到的就是已经取回的那几页；**没缓存过的条目离线没有封面图，但条目本身、备注和标签都还在**。
- 已缓存的视频离线可直接播放；未缓存的条目在断网时仍可浏览详情，点播放会给出明确的网络错误提示。
- 断网期间的改动（新增/编辑/删除）都会排队，联网后自动补传，不会丢。
- **删除一条收藏会把它留在本地的字节一起收回**：图片按 URL 精确删掉 Coil 里那一份，视频段删掉
  SimpleCache 里那一份，设置里两个占用数字当次就刷新。早期版本不会回收，删完收藏图片缓存还一路涨到上限。

## 5. 设置

顶部齿轮进入设置，六组卡片：

- **同步服务**：接口地址（要填到包含前缀的完整 base，如 `http://192.168.1.20:8787/api/v1`）、访问令牌（Bearer）、
  **上传间隔**（预设 0=不限速 / 1s / 3s / 10s / 30s，默认 3000ms；后台若回 `next_wait_ms` 以后台为准），
  底部显示本机设备标识（后端用它区分同一账号下的不同平板）。
  打包时可以用 `-PSYNC_ENDPOINT=...` 或 CI 的 Repository variable 固化默认地址；传输不加密，不再需要往包里塞公钥。
  想接自己的后台，字段、状态码与校验规则见 `docs/同步后台接口说明.md`。
- **同步队列**：待同步 / 失败条数，以及「立即重试」（把已耗尽重试次数的任务重新排队）。
- **全局悬浮收藏助手**：悬浮球常驻开关、「打开面板时自动读剪贴板」开关（关掉后只能手动点粘贴或用分享入口）、
  「悬浮球显示同步角标」开关（关掉后球上不显示数字，服务也不再订阅同步队列）。
  未授权时这里会给出跳转系统悬浮窗授权的按钮。
- **播放与缓存**：默认倍速（0.75x~2x）、视频缓存占用（`已用 / 上限`）、图片缓存占用（`已用 / 上限`）、
  缓存上限（视频 128MB~2GB 五档、图片 32~512MB 五档），以及「清空视频缓存」「清空图片缓存」两个按钮。
  两行都按目录分开报，合计数在筛选抽屉底部（那边叫「本地缓存占用」）。
  清空只删缓存文件，收藏记录、备注和标签都不受影响；**清空视频缓存还会把每张卡片上的「已缓存」标记一起抹掉** ——
  那个绿点和遮罩层里「已缓存，离线可直接播放」读的就是这个标记，只删字节不动标记就说不出「清完还显示已缓存」这种话。
  图片上限改的是整个图片加载器（Coil 的容量没有运行期改口的接口），换完目录不变、已缓存的图不丢。
- **存储明细**：点「测量存储占用」只读地量一遍应用私有目录，列到每个文件，分「表观」（文件长度）和「占盘」
  （实际占的磁盘块）两列 —— 系统「设置 → 应用 → 存储」按占盘算，几 KB 的数据库文件成串排下来会比表观大不少，
  两列一起看才对得上数。末尾还给出收藏表的行数（未软删 / 墓碑 / 总行）与每行平均字节，
  用来判断「删完收藏库里还剩多少字节」是数据还在、还是空页没回收。测量不删不改，结果可长按复制。

通知栏那条静默常驻通知带两个动作：「打开设置」直接跳到主 App 设置页，「停止」会同时关掉助手偏好，
下次进主 App 不再自动拉起。

## 6. 常见问题

**悬浮球没有出现？** 系统把「显示在其他应用上层」收回了（部分厂商在重启或清理后台后会重置）。
进设置重新授权，或在设置里把助手开关关掉再打开。

**面板里点「粘贴剪贴板链接」提示读不到？** 请先在视频 App 里点一次「复制」，再回来粘贴；
部分厂商 ROM 会在剪贴板里带隐私遮罩，这种情况用「分享 → 收藏助手」最稳。

**删除后云端还在？** 删除是软删除 + 排队上传，遮罩层的详情（竖屏抽屉、横屏右栏）会先显示「等待后台上传」，同步成功后本地条目才彻底清理。

**换了平板怎么恢复收藏？** 在新平板设置里指向同一个后端地址，冷启动时本地缓存是空的，App 会自动取回第一页；
往下滚一页一页补，或在筛选抽屉里点「从后台加载」手动取下一页。想立刻看全，就一直滚到尾部出现「到底了」。
